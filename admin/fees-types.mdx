Fee types are the categories your institution uses to classify charges — such as tuition fees, exam fees, or lab fees. Before you can configure fees for any academic program, you need to set up the relevant fee types here. Think of fee types as the building blocks that your program fee structures are assembled from.

## Creating a Fee Type

Navigate to **Admin → Fee Types** to manage your institution's fee categories.

<Steps>
  <Step title="Open the Add Fee Type form">
    Click **Add Fee Type** to open the creation form.
  </Step>
  <Step title="Enter the fee type name">
    Type a clear, descriptive name for the fee category. Common examples include:
    - Tuition Fee
    - Exam Fee
    - Lab Fee
    - Library Fee
    - Sports Fee

    Choose names that will be recognisable to the staff who configure program fees later.
  </Step>
  <Step title="Save the fee type">
    Click **Save** to add the fee type to your list. It will be active by default and available immediately for use in program fee configuration.
  </Step>
</Steps>

## Managing Fee Types

Once fee types are created, you can view, rename, and change their status from the Fee Types list.

<Steps>
  <Step title="View active and inactive fee types">
    The Fee Types list is filtered by status. Switch between the **Active** and **Inactive** tabs to see all fee types regardless of their current state.
  </Step>
  <Step title="Rename a fee type">
    Click the edit icon next to any fee type to update its name. The change takes effect immediately and is reflected wherever the fee type is already in use.
  </Step>
  <Step title="Activate or deactivate a fee type">
    Toggle the status of a fee type to activate or deactivate it. Inactive fee types are hidden from program fee configuration forms but are preserved for historical records. Reactivate a fee type at any time to make it available again.
  </Step>
</Steps>

<Tip>
  Fee types you create here are used when building out fee structures for your academic programs. Head to the [Programs](/academics/programs) section to see how fee types map to per-program charges that appear on student fee invoices.
</Tip>
